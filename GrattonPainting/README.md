# GrattonPainting

Single-site marketing website for **Gratton Painting LLC** using the Sunset Bold design.

**Phone:** (941) 773-3021

## What's included

| Path | Description |
|------|-------------|
| `index.html` | Main production homepage |
| `assets/` | Shared logo SVGs and `site.js` for navigation/form behavior |
| `versions/v2-sunset-bold/styles.css` | Sunset Bold stylesheet used by the homepage |

## Local preview

From this folder:

```bash
python3 -m http.server 8080
```

Then open:

- **Site:** http://localhost:8080

## Deploy

Static hosting works on GitHub Pages, Netlify, or Cloudflare Pages. Point the host at this folder's root and set `index.html` as the entry page.
